# Design Baseline — docs-guide-review (기준 설계 문서)

> 이 그룹의 요구사항·설계 결정의 단일 기준. append-only — 항목은 지우지 않고 상태만 바꾼다.

## 0. 질의 수준 (Autonomy Level)

- [ ] **적극(Thorough)**
- [ ] **보통(Balanced)**
- [x] **간략(Lean)** — 사용자가 범위("모두 수정", README 포함)를 정했고 지적 목록·재검수 결과가 항목을 고정했다.

선택: **간략** · 선택일: 2026-10-21

## 1. 목적 / 배경

`docs/guides/` 6개 문서(index.html·ARCHITECTURE.md·DEVELOPMENT.md·workflows/*.html 3개)를 코드(main `f8291f2`)와
대조한 검수가 34건을 지적했다(HIGH 0 · MED 9 · LOW 25). 감독자 재검수에서 31건 맞음, 2건 일부 맞음(A-12·D-03 — 범위를
좁힘), 1건 판정 보류(S-04). 판정 보류를 뺀 전부와 누락 표를 고치고, README 에 같은 사실이 틀리게 적힌 곳도 고친다.
