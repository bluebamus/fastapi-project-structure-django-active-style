## 2. 계약

### 2-1. 지원 구성
- 학습자 진입 경로 3종: 저장소 `README.md` · `docs/README.md` · 생성기 출력
- 두 예제 기능이 각 방식의 참조 구현: `catalog`(ORM) · `reports`(Raw)

### 2-2. 위협 모델
- **방어한다**: 학습 경로의 **단절** — 끊긴 링크, 사라진 예제, 예제가 다른 방식으로 바뀜,
  진입점이 가이드를 가리키지 않음, 저장소 정체성 오표기
- **방어하지 않는다**: 문장의 품질·가독성·번역. 자동 검사가 불가능하고 사람 판단 영역이다.
  문서가 **최신 코드를 정확히 서술하는지**도 전수 검증하지 않는다 — 검사하는 것은 참조
  대상의 실재와 Base 사용 여부까지다.
