기능 경계

각 기능은 app/features/<name> 아래에 View·서비스·저장소·스키마·모델을 모읍니다. 기능은 다른 기능을 import 하지 않습니다(예외: auth → user). 기능 사이의 데이터 연결은 FK 없는 값(예: Reply.post_id)으로 합니다.

관리 화면은 app/features/admin.py 가 registry 가 모은 각 기능의 admin_views 로 조립합니다(ADMIN_DISABLED=false 일 때).
