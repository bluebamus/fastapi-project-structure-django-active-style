3. 앱 만들기 — 생성기와 표준 레이아웃

uv run python -m scripts.new_app <name>                 # 뼈대
uv run python -m scripts.new_app <name> --with-admin    # admin.py(빈 admin_views) 포함
uv run python -m scripts.new_app <name> --force         # 이미 있는 앱을 의도적으로 다시 만들 때만
  • 이름은 파이썬 식별자(snake_case)여야 하고 예약어·app/features 밖 경로는 거부됩니다. 대상 앱이 이미 있으면 기본적으로 중단합니다. --category 는 동작에 영향 없는 호환용 옵션입니다.
  • 생성물: api/routers/v1/·models/·schemas/·services/·repositories/·dependencies/·tests/ 패키지, 빈 <name>_router 가 있는 api/routers/router.py, 예시 주석만 있는 dependencies/<name>_dependencies.py, (--with-admin) admin_views: list[type] = [] 인 admin.py.
  • 만들지 않는 것: models/models.py, apps.py, v1 엔드포인트 파일, 스키마·Repository·Service 본문, 테스트, migration. 아래를 직접 작성합니다.
  • 손으로 만들어도 되지만 라우터 변수명은 반드시 <name>_router 입니다. 그 밖의 등록 규약은 ARCHITECTURE §2가 정합니다. main.py·migrations/env.py· app/features/admin.py 는 열지 않습니다.
app/features/<name>/
├── __init__.py                 # 패키지 선언만 (부수효과·재노출 금지)
├── apps.py                     # ready() — 부팅 초기화 훅이 필요할 때만
├── api/routers/
│   ├── router.py               # <name>_router — v1 서브라우터를 include
│   └── v1/<name>.py            # 엔드포인트
├── models/
│   ├── __init__.py             # 모델 재노출
│   └── models.py               # ORM 모델
├── schemas/                    # 요청·응답 DTO
├── repositories/               # BaseRepository / RawRepositoryBase 상속
├── services/                   # BaseService 상속
├── dependencies/<name>_dependencies.py   # get_<name>_service / get_<name>_service_readonly
├── exceptions.py               # 기능 예외 (선택)
├── admin.py                    # ModelView + admin_views (모델이 있으면 사실상 필수)
├── tasks.py                    # Celery 태스크 — 필요할 때만 (워커가 registry 로 발견)
└── tests/                      # 이 기능의 테스트
용도 쓰는 이름 쓰지 말 것
기능 예외 exceptions.py <name>_exception.py
기능 의존성 dependencies/ 패키지 (단일 dependencies.py 도 허용) dependency.py
SQLAdmin 뷰 admin.py api/<name>_admin.py
Celery 태스크 기능 폴더의 tasks.py (선택) app/celery/ 에 기능 태스크, 기능별 worker/
초기화 apps.py 의 ready() __init__.py 의 import 부수효과

최종 URL 은 prefix 의 합입니다. 디렉터리 이름으로 계산되지 않습니다.

registry 의 "/api"  +  router.py 의 include prefix "/v1/catalog"  +  v1 엔드포인트 "/products"
= /api/v1/catalog/products

# app/features/catalog/api/routers/router.py
catalog_router = APIRouter()
catalog_router.include_router(products_v1.router, prefix="/v1/catalog", tags=["Catalog"])

URL 버전은 위 prefix 문자열이 정합니다(버전 설정은 없습니다). tests/test_openapi_contract.py 가 모든 operation 의 summary·description·유일한 operation_id·tag, 파라미터·스키마 필드의 description, 그리고 app/core/tags_metadata.py 와 실제 tag 의 양방향 일치를 강제합니다. 새 경로를 추가하면 tests/test_route_inventory.py 의 목록과 README 의 API 표를 함께 갱신합니다.
