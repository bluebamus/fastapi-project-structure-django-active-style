PROJECT GUIDE

테스트

테스트 명령, 마커, CI job 과 검증 층입니다.

허브 부팅 설계 API 설정 요청 인증 기능 개발 테스트 운영

도식은 고정 버전 Mermaid CDN을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

기본 명령

uv run python -m pytest                    # 전체 — mysql 마커는 MySQL 이 없으면 skip
uv run python -m pytest -m "not mysql"     # CI gate job 과 같은 범위(skip 0)
uv run ruff check . && uv run mypy .

uv run pytest 대신 python -m pytest 를 씁니다. pytest 설정이 DEBUG=true·ENV=test 를 주입하고 tests/ 와 app/features/*/tests/ 를 함께 수집합니다. 단위 테스트는 SQLite 와 가짜 Redis(fakeredis)를 써서 외부 인프라 없이 돕니다. CI gate job 은 실수로 생긴 실물 접속이 닫힌 포트에서 실패하도록 REDIS_HOST=127.0.0.1·REDIS_PORT=16392 를 줍니다.

MySQL·E2E

docker compose -f compose.test.yaml up -d --wait
uv run python -m pytest -m mysql
docker compose -f compose.test.yaml down -v

mysql 마커 테스트는 compose.test.yaml 의 MySQL 8.4(127.0.0.1:3310, MYSQL_TEST_PORT)가 필요합니다. e2e 마커는 -m e2e 를 줄 때만 수집되며(tests/e2e/conftest.py) compose.e2e.yaml 위에서 실제 uvicorn·Celery·Chromium 을 띄웁니다. 명령과 포트는 README 테스트가 정본입니다.

CI 는 세 job 입니다: gate(-m "not mysql"), MySQL(compose.test.yaml + -m mysql), e2e(compose.e2e.yaml + -m e2e). skip·xfail 이 하나라도 있으면 실패합니다.

변경 완료 조건

성공 경로만이 아니라 잘못된 입력, 미인증, 권한 부족, 없음, 충돌, 저장소 실패를 검증합니다. 외부 서비스가 필요한 테스트를 생략했다면 결과에 명시하고 CI 에서 보완합니다.
