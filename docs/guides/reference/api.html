PROJECT GUIDE

API 레퍼런스

전체 operation 과 뷰마다 선언된 접근 수준입니다.

허브 부팅 설계 API 설정 요청 인증 기능 개발 테스트 운영

도식은 고정 버전 Mermaid CDN을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

공통 규칙

  • 기능 API 는 /api/v1 아래, /health·/ready 는 루트입니다.
  • 모든 뷰는 접근 수준을 하나 선언합니다: Public(인증 없는 읽기), PublicWrite(인증 없는 쓰기), LoginRequired, SuperuserRequired. 기동 시 AccessPolicyGuard 가 검사합니다. 작성자·본인 규칙은 서비스가 판정합니다(아래 "추가 규칙").
  • 토큰이 없거나 무효면 401(WWW-Authenticate: Bearer), 슈퍼유저가 아니거나 소유권이 없으면 403 입니다.
  • rate limit 은 가입·로그인 두 경로만입니다. 초과하면 429 + Retry-After.
  • 검증 오류는 422 ErrorResponse(VALIDATION_ERROR), Redis 연결 장애는 503 입니다.
  • 요청·응답 스키마는 /docs·/openapi.json 에서 봅니다. 이 둘은 DEBUG=true 일 때만 열립니다.
