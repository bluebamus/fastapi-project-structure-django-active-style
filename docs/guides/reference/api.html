읽는 법

이 페이지는 실행 중인 FastAPI 애플리케이션의 app.openapi() 결과에서 생성했습니다. 라우터 prefix, HTTP 메서드, operationId, 파라미터, 요청·응답 스키마가 실제 코드와 같은 조립 경로를 거칩니다.

경로 23개, 오퍼레이션 38개, 스키마 35개. OpenAPI의 security 선언은 인증 필요 여부의 한 근거이며, 소유권 검사는 Service 계층에서 추가로 수행될 수 있습니다.

POST /api/v1/auth/login

로그인(OAuth2 password)

username/password(form)로 access·refresh 토큰을 발급합니다. IP 별·IP+사용자명 별 시도 횟수가 제한됩니다.

operationId: authLogin · 인증 선언: OpenAPI상 없음 · 요청 본문: Body_authLogin

파라미터위치필수형식설명
없음

응답: 200 Successful Response, 401 인증 실패, 429 시도 횟수 초과(`Retry-After` 헤더 참고), 422 Validation Error

POST /api/v1/auth/logout

로그아웃

Refresh Token 의 로그인 세션(family)을 폐기합니다. 이미 쓰였거나 폐기된 토큰이어도 204 입니다. access token 은 만료(기본 15분)까지 유효합니다.

operationId: authLogout · 인증 선언: OpenAPI상 없음 · 요청 본문: RefreshRequest

파라미터위치필수형식설명
없음

응답: 204 Successful Response, 401 인증 실패, 422 Validation Error

토큰 재발급(회전)

operationId: authRefresh · 인증 선언: OpenAPI상 없음 · 요청 본문: RefreshRequest
