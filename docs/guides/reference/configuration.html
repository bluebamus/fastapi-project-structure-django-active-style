환경 설정 레퍼런스

.env.example과 설정 모델을 기준으로 값의 유입과 검증 책임을 설명합니다.

허브부팅설계 API요청인증 기능개발운영

사용 원칙

설정의 단일 진입점은 config.py이며 환경 변수 이름과 예시는 .env.example에서 확인합니다. 운영 비밀은 저장소에 커밋하지 않고 비밀 관리 시스템에서 주입합니다.

예제 환경 변수

변수예제 값인접 설명
DEBUGtrue- false: INFO 로그만 출력, 테이블 자동 생성 비활성화 (Alembic 사용), /docs 비활성화
ADMIN_DISABLEDfalse예전 "무인증 허용" 확인 플래그는 없어졌다(남아 있어도 무시된다 — 지워도 된다).
ENVdevelopment(HTTPS 로만 전송 — HTTP 로 띄우면 로그인해도 쿠키가 붙지 않는다).
SERVER_HOST0.0.0.0쓰지 않으면 ADMIN_DISABLED=true, 쓰면 프록시·방화벽으로 /admin 접근 범위를 좁히는 것을 권장한다.
SERVER_PORT8000
TIME_ZONEAsia/Seoul예시: Asia/Seoul, UTC, America/New_York
MYSQL_HOSTlocalhostMySQL 서버 호스트 (IP 또는 도메인)
MYSQL_PORT3306MySQL 서버 포트
MYSQL_USERrootMySQL 접속 사용자명
MYSQL_PASSWORDyour-mysql-password-change-this이 예시 값과 빈 값 모두 test 외 모든 ENV 에서 기동이 거부된다.
MYSQL_DATABASEfastapi_db사용할 데이터베이스 이름
DB_ROUTER_ENABLEDfalse구현: app/core/db/router.py
DB_REPLICATION_ENABLEDfalse- false: 라우터를 켜도 replica 가 없으므로 읽기도 primary 로 나간다.
DB_READ_STICKY_AFTER_WRITEtruefalse 로 두면 읽기 분산은 늘어나지만 read-after-write 일관성을 잃는다.
MYSQL_REPLICA_HOSTS[]예: MYSQL_REPLICA_HOSTS=["10.0.0.11", "replica-b.example.com:3307"]
MYSQL_REPLICA_PORT3306포트를 명시하지 않은 replica 에 적용할 기본 포트
REDIS_HOSTlocalhostRedis 서버 호스트
REDIS_PORT6379Redis 서버 포트
REDIS_DB0Redis 데이터베이스 번호 (0-15)
REDIS_PASSWORDRedis 비밀번호 (설정하지 않으면 인증 없이 접속)
CORS_ALLOW_ORIGINS["*"]특정 Origin만 허용: ["http://localhost:3000", "https://example.com"]
CORS_ALLOW_CREDENTIALSfalse자격 증명(쿠키, Authorization 헤더) 허용 여부
CORS_ALLOW_METHODS["GET", "POST", "PUT", "DELETE", …허용할 HTTP 메서드 (JSON 배열 형식, 미설정 시 ["*"])
CORS_ALLOW_HEADERS["*"]허용할 HTTP 헤더 (JSON 배열 형식)
CORS_MAX_AGE600Preflight 요청 캐시 시간 (초)
LOG_CONSOLE_ENABLEDtrue예: 컨테이너에서 파일만 수집할 때 ENV=production, LOG_FILE_ENABLED=true, LOG_CONSOLE_ENABLED=false
LOG_FILE_ENABLEDtrue파일 로그 출력 활성화 — ENV=staging/production 일 때만 파일 핸들러를 붙인다
LOG_SQL_ECHO_ENABLEDfalsestaging/production 에서 true 로 두면 기동이 실패한다(의도된 동작).
LOG_APP_LEVELS예: LOG_APP_LEVELS=blog=DEBUG,celery=INFO,sqlalchemy=WARNING
LOG_FILE_LEVELINFO파일 로그 레벨 (파일에는 INFO 이상만 기록하는 것이 일반적)
LOG_DIRlogs파일: 웹 app.log·error.log, Celery 워커 celery.log·celery-error.log (에러 파일은 ERROR 이상)
LOG_MAX_SIZE_MB10하루 안에서 이 크기(MB)를 넘으면 app.log.YYYY-MM-DD.1, .2 … 로 나눈다. 0 = 나누지 않음
LOG_RETENTION_DAYS30회전이 안전하지 않다 — 그때는 LOG_FILE_ENABLED=false 로 두고 stdout 을 수집기/logrotate 로 보낸다.
ACCESS_LOG_ENABLEDtruetrue: 모든 API 요청에 대해 접속 로그를 DB에 저장
TRUSTED_PROXY_HOPS0예전 bool 설정(신뢰 여부 true/false)을 대체한다 — true 였다면 프록시 수(보통 1)로 옮긴다.
ACCESS_LOG_RETENTION_DAYS3650 = 삭제하지 않음(무기한 보존). 음수는 기동 시 설정 오류. beat 를 띄우지 않으면 지워지지 않는다.
SESSION_COOKIE_NAMEsession/admin 세션 쿠키(admin_session)와는 별개다.
SESSION_SECRET_KEYchange-this-session-secret-key생성 방법: uv run python -c "import secrets; print(secrets.token_urlsafe(48))"
ACCESS_TOKEN_SECRET_KEYchange-this-access-token-secret-key생성 방법: uv run python -c "import secrets; print(secrets.token_urlsafe(48))"
REFRESH_TOKEN_SECRET_KEYchange-this-refresh-token-secret-key생성 방법: uv run python -c "import secrets; print(secrets.token_urlsafe(48))"
ACCESS_TOKEN_EXPIRE_MINUTES15access 토큰은 만료 전 폐기 수단이 없다 — 로그아웃·재사용 탐지는 refresh 만 끊는다. 짧게 둔다.
REFRESH_TOKEN_EXPIRE_DAYS7Refresh Token 만료 시간 (일, 기본값: 7일). Redis 의 refresh 기록 TTL 도 같다.

확장 방법

  1. 설정 필드를 타입과 안전한 기본값으로 추가합니다.
  2. .env.example에는 비밀이 아닌 예시와 설명을 추가합니다.
  3. 서로 의존하는 값은 설정 검증 단계에서 빠르게 실패시킵니다.
  4. 배포 매니페스트와 테스트 fixture를 함께 갱신합니다.
